wryte

A tag-first (markdown) rich text editor with a Trix-compatible API, built on ProseMirror. Initial content lives in a hidden <input> that the editor reads and keeps in sync (like Trix). Select text for a formatting bubble; press Enter on an empty line to reveal a (+) button for block insertion. Right-click / long-press opens a context menu. Drop or paste an image file to exercise the upload pipeline. No toolbar by default.
